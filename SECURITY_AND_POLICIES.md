# Security and launch checklist

- [ ] Use HTTPS only.
- [ ] Enable Supabase email verification and strong password rules.
- [ ] Keep service-role and merchant secret keys on a trusted server only.
- [ ] Review every RLS policy before production.
- [ ] Add rate limits and abuse reporting.
- [ ] Add moderation rules and a prohibited-content policy.
- [ ] Never allow account credentials, OTPs, recovery codes, or account transfers.
- [ ] Do not accept payment screenshots as proof of completed payment; verify transaction server-side.
- [ ] Add dispute, refund, cancellation, and seller conduct workflows.
- [ ] Add privacy policy, terms of service, contact details, and data deletion process.
- [ ] Test with dummy users and sandbox payments.
- [ ] Arrange independent security review before handling real payments.

## Marketplace eligibility
Only list lawful digital services and official referral promotions. Review the current terms of every third-party platform. Do not represent that an exchange or social network endorses this marketplace unless it has given written permission.
